# SRC-02 證券交易法

- 官方來源：[全國法規資料庫｜證券交易法第 36 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?flno=36&pcode=G0400001)
- 核對日期：2026/11/23
- 教學問題：公司要在什麼時候公告資訊並向主管機關申報？
- 適用對象：已依證券交易法發行有價證券的公司。特殊情形依主管機關另定的規定辦理。

## 第 36 條第 1 項的一般期限

| 資訊類型 | 公告及申報期限 |
| --- | --- |
| 年度財務報告 | 會計年度結束後 3 個月內 |
| 第一、二、三季財務報告 | 各季結束後 45 日內 |
| 上月營運情形 | 每月 10 日以前 |
